--------------
The targeted sky/cloud/light host calls are covered by exact source copies/sections plus the external LWJGL artifacts. This audit is static. It verifies source presence, copy hashes and declared ranges; it does not claim Java compilation, OpenGL context creation, shader compilation or a running Minecraft client.
